## 📖 Overview

**Halikarnas Saat** is an elegant, multi-page e-commerce web platform designed for showcasing and retailing fine wristwatches, chronographs, automatic mechanisms, and wearable technology. The project combines modern visual design, intuitive product browsing, responsive layouts, and interactive shopping cart functionality.

🇹🇷 **Dil Notu:** Web sitesi arayüzü, gezinme menüleri, ürün katalogları, teknik özellik tabloları ve sepet adımları tamamen **Türkçe** olarak hazırlanmıştır (*"Halikarnas Saat - Kaliteli ve Güvenilir Saatler"*).

Built with semantic **HTML5**, **Bootstrap 5.3.8**, custom **CSS3**, and vanilla **JavaScript (ES6+)**, the platform ensures fluid responsiveness across all device form factors — from compact smartphone screens to high-resolution desktop monitors.

🔗 **Live Deployment:** [https://kucukagtas.github.io/halikarnasSaat/](https://kucukagtas.github.io/halikarnasSaat/)

## ✨ Key Features

- **📱 Pixel-Perfect Responsive Layout:** Seamlessly scales across all screen sizes, from mobile phones to high-resolution desktop displays, ensuring consistent readability and navigation.
- **🧭 Multi-Category Mega Dropdown Navigation:**
  - Responsive navbar with collapsible toggle for mobile devices.
  - Six rich category dropdown menus:
    - **Erkek Saat:** Klasik Saatler, Spor & Kronograf, Otomatik Modeller, Dalış Saatleri
    - **Kadın Saat:** Klasik & Şık, Rose Gold Modeller, Deri Kordonlu, Taşlı & Mücevher Saatler
    - **Mekanizmalar:** Otomatik Mekanizma, Kurmalı, Quartz, Solar & Kinetik
    - **Giyilebilir Teknoloji:** Akıllı Saatler, Spor & Nabız Takip, Hibrit Modeller, Akıllı Bileklikler
    - **Özel Saatler:** Sınırlı Üretim, Vintage & Retro Koleksiyon, İsviçre Yapımı, Titanyum Kasa Saatler
    - **Markalar:** Citizen, Tissot, Hamilton, Casio
- **🏠 Storefront & Homepage:**
  - **Top Bar:** Integrated search bar, brand identity logo, and quick user actions (*Hesabım*, *Listem*, *Sepetim*).
  - **Hero Banner Slider:** Multi-slide carousel showcase highlighting flagship watch models with smooth transitions.
  - **İndirim Vitrini Showcase:** Curated selection of featured timepieces in a balanced responsive grid with interactive wishlist buttons, discount tags, and price comparisons.
- **🔍 Product Details & Showcase:**
  - **Lightbox Gallery:** High-resolution zoomable image modal triggered on click.
  - **Multi-Angle Thumbnails:** Photographic gallery with multiple perspective angles.
  - **Product Specifications:** Detailed technical overview highlighting mechanism type, case dimensions, scratch-resistant sapphire crystal, water resistance, and stainless steel craftsmanship.
  - **Customization Options:** Dropdown selectors for case diameter and dial color variations.
  - **Call to Action:** Prominent *"Sepete Ekle"* and *"Listeme Ekle"* buttons adapting smoothly across devices.
  - **Related Recommendations:** Recommendation grid highlighting complementary watch models.
- **🛒 Shopping Cart Experience:**
  - **Order Items Management:** Visual product thumbnails, descriptions, color and size details, quantity adjustments, and easy removal.
  - **Free Shipping Incentive:** Highlight banner indicating free delivery qualification.
  - **Cart Action Controls:** Quick action buttons for continuing shopping or clearing the cart.
  - **Order Summary:** Real-time subtotal, shipping fee, tax breakdown, total calculation, and direct checkout CTA.
  - **Trust & Guarantee Badges:** 256-Bit SSL encryption, 14-day return policy, and 100% original product authenticity guarantee.
- **🔝 Smooth Scroll-to-Top:** Floating action button that appears automatically when scrolling down, offering instant smooth navigation back to the top of the page.
- **🎨 Curated Luxury Brand Palette:**
  - Primary Forest Emerald: `#519d79`
  - Dark Emerald (Hover/Active): `#3f7b5f`
  - Light Emerald Surface: `#eef7f2`
  - Accent Warning Gold: `#ffc107`
  - Deep Neutral Slate: `#2b3035`
- **⚡ High Performance & Lightweight Assets:** Modern AVIF image formats, zero bloated runtime frameworks, zero external build dependencies.

## 🚀 Getting Started

To view or develop this project locally on your machine:

### 1. Clone the Repository

```bash
git clone https://github.com/kucukagtas/halikarnasSaat.git
```

### 2. Navigate to the Project Directory

```bash
cd halikarnasSaat
```

### 3. Run Locally

Since this is a pure static web application, no compilation or build steps are required:

* **Directly in Browser:** Double-click `index.html` or drag it into any modern web browser (Chrome, Safari, Firefox, Edge).
* **VS Code Live Server:** Right-click `index.html` and select **"Open with Live Server"**.
* **Via Node.js `serve`:**
  ```bash
  npx serve .
  ```
* **Via Python HTTP Server:**
  ```bash
  python3 -m http.server 8000
  ```
